# Artist music folders

Each artist has a folder and a playlist.json.

To add music later:
1. Upload audio into the artist's folder.
2. Name files with numeric prefixes such as 01-song.mp3, 02-song.mp3, 03-song.mp3.
3. Add each track to that folder's playlist.json in the same order.

The website plays playlist.json from top to bottom, giving you a stable saved order.
