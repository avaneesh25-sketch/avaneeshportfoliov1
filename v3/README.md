# V3 desk study
Open /v3/ on the preview deployment, or run npx serve from the repo root. This isolated scene uses the imported Poly Haven desk GLB and Wooden Studio HDRI. One scene unit is one metre. The long tabletop axis is normalized to 1.8m using uniform scaling, with original proportions preserved. The floor is y=0. The live dimensions are calculated from the model bounds. Scale guide footprints are for placement only; AT-LP60X is 359.5 × 373.3 mm, other footprints are approximate. No actual accessories or story interactions are included at this stage. Rendering is event-driven (no permanent animation loop). Production files are untouched.
