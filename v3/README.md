# V3 populated desk
All objects are present as local GLB candidates or explicitly labeled procedural fallbacks. The desk uses the writing-desk candidate first and the previous wooden desk as a local alternate. A 1.8 × 0.75 × 0.75 m footprint is intentional. GLB fetch retries once (8-second network timeout), then local alternatives are tried; if all fail, simple geometry preserves the scene. Asset provenance is recorded in assets/models/ASSET-SOURCES.md and import reports. Inspect window.__v3AssetReport for live loader outcomes. Branded turntable/earbud substitutes are not exact replicas. Walk/sit remains the existing interaction; exploded views, screen content and music are not yet implemented. Production is untouched.
